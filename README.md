# mini-java-utils

A tiny Java utility library designed for experimentation, learning, and creating meaningful pull requests.

Java version: 21

## Features

- Safe string trimming
- Default handling for blank strings
- Join collections into a delimited string
- Format Java `Duration` values into a readable string

## Getting started

### Prerequisites

- Java 21+
- Maven 3.9+

### Build

```bash
mvn -B test
